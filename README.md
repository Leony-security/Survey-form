# 📋 Tech Career Survey Form

A modern, responsive, and semantically structured web form developed as part of my career transition track into professional software engineering and AppSec.

## 🚀 About the Project
This project aims to collect feedback on tech resumes and remote work modalities, strictly adhering to W3C web accessibility (A11y) guidelines and native HTML5 specs.

## 🛠️ Key Technical Features
* **Semantic HTML5:** Proper use of structural and form tags (`<form>`, `<fieldset>`, `<legend>`, `<select>`, `<textarea>`).
* **Web Accessibility (A11y):** Explicit label-to-input association using `for` and `id` attributes for screen reader compatibility.
* **Native HTML5 Validation:** Enforced required fields (`required`), numerical constraints (`min`, `max`), and strict input pattern checks (`email`, `number`).
